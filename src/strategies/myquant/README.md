## Token 管理

未来接入时，真实 Token **只能**放在项目根目录的 `.env` 文件中，
键名为 `MYQUANT_TOKEN`（见根目录 `.env.example` 模板）。

注意事项：

- `.env` 已被 `.gitignore` 忽略，不会进入 Git
- **禁止**将 Token 写入本目录下的任何文件
- **禁止**将 Token 提交到 Git 仓库
- **禁止**将 Token 硬编码进策略代码

## 迁移注意事项

从聚宽 / 本地策略迁移到 MyQuant 时需注意：

- API 差异（数据获取、下单接口）
- 回测引擎撮合规则差异
- 复权方式差异
- 时间处理（交易日历）

迁移后必须重新回测验证，不得直接沿用原回测结论。
