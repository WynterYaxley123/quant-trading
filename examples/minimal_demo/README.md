# Synthetic minimal demo

From the repository root, in the portable developer container:

```sh
python -m examples.minimal_demo
```

SYNTHETIC DEMO ONLY. Fixed seed 10719 creates eight artificial identities,
raw factor vectors and explicitly matured labels. Existing production functions
enforce six calendar months, at least 30 training dates, independent H10/H40/H120
Ridge alpha 0.01, population z-score fusion and capped Top5 sizing.

The small universe illustrates architecture; it does not replace the admitted
107-industry production contract. It generates no market data downloads, broker
orders, execution mapping, account state, NAV or performance claim.
