# SWL1 真实数据来源资格审查

当前决定为 **C / DATA_SOURCE_NOT_READY**。本轮审计 12 类来源，访问 19 个指定
公开文档入口，取得 17 份响应哈希，其中 15 份的具体声明通过原始字节核验。
另外两份只是页面外壳。申万分类说明直接访问返回 403，公告页仍不可取得；
补全公开证书链后的访问返回 508，没有关闭 TLS 验证或绕过访问控制。

原始内容只在内存中审查，公开仓库保存 URL、发布时间范围、取得时间、版本、
哈希、事实摘要和限制。没有下载真实行情、登录账户、发送供应商邮件、购买数据、
接受合同或生成生产密钥。详见[证据记录](../../config/research/swl1-source-qualification-evidence.json)。

## 来源与权利

申万分类和历史成员由 SWS 原始发布；历史表经过固定版本 CNEquity 整理。
个股行情以 TDX 为主要路径，源码还有替代提供者路径。**实际公司行动来源是
TDX xdxr；Sina 提供复权因子。** BaoStock 提供上市退市基本资料及复权回退来源。
CNEquity 派生复权因子、交易日历和行业收益；项目 SWL1 通过显式 L2→L1 映射
进行等权重建。派生结果不等同于官方一级行业指数。

此次更正写入新的来源清单，PR34 旧报告保持原字节。上游固定在
1650e384a3fd1f67a70144a489acc91432f1df27，未修改源代码或数据湖。

真实完整数据集授权仍为 0。BaoStock 官方说明支持免费 API 和本地保存分析，
因此相关权利记为有条件的文档支持，不能忽略上游许可、再分发和留存范围。
TDX 的交易所授权属于提供者，不能自动传递给本项目。TDX 和 Sina 的通用条款
存在使用限制，当前接口的具体授权仍需书面确认。软件 Apache-2.0 许可不授予
数据权利。上交所的非商业浏览下载条款也不构成无限制的数据湖使用许可。

[权利矩阵](../../reports/research/swl1_source_qualification/rights-matrix.json)
逐项区分访问、保存、研究、自动处理、派生、回测、商业使用、展示、再分发、
留存和修订权限。当前条款不被自动追溯适用于历史所有时期。

## PIT 和质量

找到了申万官方 2021 分类说明的索引线索，能指向真实的版本变更资料，但未取得
可核验原文。它不能替代完整历史成员快照和当时接收凭据。成员 adapter 没有保留
更新列，更没有完整公布、观察与接收时间；历史成员继续是 effective-dated
reconstruction。旧 Tier 和旧研究结果不能回写。

BaoStock 行业接口示例是证监会分类，不能作为申万成员的独立证明。
其复权 PDF 与因子字段说明对前后复权比值方向的表述需要供应商解释。
源码中 raw×hfq、qfq 锚点以及 adjusted/raw 回退公式已经定位；历史数值正确性
和不同提供者的方法等价性尚未核验。

官方文档描述了停牌占位行情、数据纠正记录、上市和退市日期。取得的一份
上交所摘牌公告明确区分公告日与摘牌日，但一个事件不能证明完整退市覆盖。
官方休市安排只是日历方法论参照，不能证明价格最终确认。真实数值 QA 因授权
不足没有运行，覆盖数值为 null，公司行动、退市和停牌完整性均 NOT_ESTABLISHED。

## 准入与下一步

四个属于现有行业/分类合同范围的候选元数据记录实际执行了 PR34 registry，
没有为真实资料伪造合成证明，全部保持 SOURCE_UNREVIEWED。其他原始输入组件
不属于该 registry 可直接准入的 kind，没有冒充官方指数。审查结果与正式准入
分别记录；元数据哈希不是数值数据快照哈希。**真实来源正式准入为 0。**

新资格预检复用既有合同，额外验证授权用途、期限、冲突、信号时可得性、版本、
完整质量证明和独立上游来源。合成测试通过也只能得到 SYNTHETIC_ONLY。
没有建立平行 registry，没有重写原数值隔离架构。

执行[最小取得计划](swl1-source-acquisition-plan.md)：先批准发送申万请求包，
取得数据使用权和历史当时公布/接收材料；随后补齐行情、权益事件、生命周期
授权及独立盲 QA。四份供应商材料已起草但未发送，价格均未取得报价。
生产审批人、受控密钥保存、轮换吊销与外部收据长期保管必须由 owner 批准。

V1/V2 仍为 FAILED_VALIDATION，Final OOS 未开启，没有 V3 或正式预测。
旧访问隔离仍 NOT_CERTIFIED，可认证历史未见交易日为 0。Linux Docker 合成
隔离验收保留；Windows 原生量化进程隔离和正式签名权威仍未建立。
