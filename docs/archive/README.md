# Historical documentation archive

This is a **logical archive**: original documents keep their paths and bytes so
certificates, hashes and historical links remain valid. Start with the
[active documentation index](../README.md) for current setup and operation.

The [inventory](inventory.md) lists dated audit/handoff records. They describe the
observed state at their own dates; they are not current deployment instructions
or standing authorization to run research/trading. No historical report has been
deleted, relocated or rewritten to improve presentation.
